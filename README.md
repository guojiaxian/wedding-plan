# 💒 备婚计划

新人的专属备婚工具网站。Vue 3 + Express + SQLite，响应式布局，电脑 / 手机 / 平板均可舒适使用。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🏠 备婚首页 | 婚礼倒计时、预算 / 物品 / 任务 / 宾客四项进度、近期待办、预算环形概览 |
| 💰 预算规划 | 总预算与分类预算上限、支出记录、**已购物品实际价格自动计入对应分类**、超支预警 |
| 🛍️ 物品清单 | 新娘 / 新郎 / 仪式用品 / 喜品伴手礼等分类折叠分组，是否已购置勾选、预计价 / 实付价、购买渠道、筛选与分类小计 |
| 📝 筹备任务 | 婚前 12 个月 → 婚礼当周分阶段推进，截止日期、负责人、待办 / 进行中 / 已完成状态流转、逾期高亮 |
| ⏰ 婚礼流程 | 当天时间轴（时间 / 环节 / 时长 / 地点 / 负责人），可排序，一键载入经典流程模板 |
| 🎀 现场布置 | 签到区 / 仪式区 / 宴会厅 / 拍照区 / 婚房五大区域清单，就绪勾选、来源（婚庆 / 自制 / 租赁） |
| 👥 人员分工 | 总管 / 伴郎伴娘 / 迎宾 / 收礼金 / 车队等岗位卡片，职责说明、电话一键拨打、关联流程环节 |
| 💌 宾客名单 | 男方 / 女方分组、出席状态（点击循环切换）、桌位、礼金登记、搜索与筛选、人数 / 礼金统计 |
| ⚙️ 设置 | 新人姓名、婚期、场地、总预算；数据导出 / 导入 JSON 备份；重置模板 / 清空数据 |

首次启动自动载入一套中文备婚模板数据（10 个预算分类、24 件物品、20 项任务、11 个流程环节、19 项布置、8 个岗位、6 组示例宾客），开箱即用，可随时在设置页重置或清空。

## 🚀 快速开始

```bash
npm install          # 安装依赖（仅写入本项目 node_modules/）
npm run build        # 构建前端
npm start            # 启动服务 → http://localhost:19002
```

打开 `http://localhost:19002` 即可使用。

### 🎨 三套主题

内置三套配色，默认「简约清新」，可随时切换（侧边栏按钮 / 手机顶栏 🎨 循环切换 / 设置页卡片选择），选择保存在浏览器本地：

| 主题 | 风格 |
|---|---|
| 🌿 简约清新（默认） | 白 + 橄榄绿 + 莫兰迪粉，Notion 式清爽工具风 |
| 🤍 西式白花 | 象牙白 + 尤加利绿 + 香槟金，西式花园风 |
| 🌸 浪漫粉金 | 粉 + 香槟金，典雅浪漫风 |

### 🔒 与同机其他 Node 应用的隔离

本服务器上运行着多个其他 Web 应用（如 3000/18000/18002/19000 端口的服务），本项目做了完全隔离：

| 项 | 本项目占用 | 说明 |
|---|---|---|
| 生产服务端口 | **19002**（监听 0.0.0.0） | 代码内默认值；局域网设备可通过 `http://<服务器IP>:19002` 直接访问；被占用时启动即报错并提示，绝不静默抢占。⚠️ 服务无登录鉴权，请仅在可信局域网内开放 |
| 开发前端端口 | **8301**（监听 0.0.0.0） | Vite `strictPort: true`，被占用时报错退出而不是悄悄漂移到其他端口 |
| npm 依赖 | 项目内 `node_modules/` | 未安装任何全局包，未修改 npm 配置 / registry / `.npmrc` |
| 数据文件 | `server/data/wedding.db` | 项目私有 SQLite，独立目录，不使用系统共享数据库 |
| Node 运行时 | 系统自带 node ≥ 22.5 | 使用内置 `node:sqlite`，**无原生模块编译**，无需 node-gyp / Python 构建链 |

换端口启动：`PORT=8400 npm start`；开发联调指向其他后端：`API_TARGET=http://localhost:8400 npm run dev`。

### 开发模式

```bash
npm run dev:server   # 终端 1：后端 API（19002）
npm run dev          # 终端 2：Vite 前端热更新（8301，/api 自动代理到 19002）
```

## 🚀 线上部署

生产机（阿里云）一键部署与运维见 **[DEPLOY.md](./DEPLOY.md)**：git 同步代码 → `./deploy/deploy.sh` 完成构建、systemd 服务安装（`MemoryMax=400M`）与部署自检；数据库与日志自包含在项目目录、不入 git，线上/线下数据隔离。

## 🗄️ 数据

- 存储于本机 SQLite：`server/data/wedding.db`
- 备份：设置页「导出备份」下载 JSON；恢复：设置页「导入备份」
- 多设备迁移：导出 → 在新设备导入即可

## 📁 结构

```
├── server/          # Express + node:sqlite
│   ├── index.js     # REST API + 静态托管
│   └── db.js        # 建表 / CRUD / 模板数据
├── src/             # Vue 3 + Pinia + Vue Router
│   ├── views/       # 10 个页面
│   ├── components/  # UiModal / RingChart / EmptyState
│   ├── stores/ api/ router/ styles/
└── vite.config.ts
```
